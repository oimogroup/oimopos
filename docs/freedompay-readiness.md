# Проверка сайта для Freedom Pay — 22.10.2026

Сверены банковская справка от 22.10.2026, данные свидетельства ИП и опубликованные страницы Oimo. Получатель и ИНН клиента в банковской справке совпадают со свидетельством. ИНН клиента и ИНН банка указаны отдельно; номер счёта взят из строки «Расчётный счёт».

**Реальные реквизиты подготовлены и проверены локально. Для их появления на опубликованном сайте нужно импортировать `.runtime/seller-render.env` в Environment сервиса Render и указать рабочий телефон.** Репозиторий GitHub публичный; шаблон в коде содержит пустые поля для персональных и банковских реквизитов. Локальный файл импорта исключён из Git и Docker-контекста.

## Что ещё необходимо

- Получить рабочий телефон владельца и импортировать подготовленные реквизиты в Render. До этого отметку «Проект документа» не снимать.
- Проверить входящие письма на support после настройки MX/маршрутизации. Для обращений уже есть резервный Gmail в контактах.
- Получить одобрение магазина Freedom Pay, ID и секрет мерчанта, пройти тестовые платежи и возврат. Код не включает настоящий эквайринг автоматически.

На момент проверки `oimopos.com` открывает Oimo по HTTPS, `/health` отвечает успешно, регистрация разрешена с этого домена; `www.oimopos.com` перенаправляет на основной адрес. На некоторых DNS ещё может оставаться отрицательный кэш от прежних отсутствующих записей.

Технические параметры и сценарий запуска: [инструкция настройки](freedompay-setup.md). Перечень требований: [официальная анкета Freedom Pay KG](https://freedompay.kg/anketa). Проверка страниц и документов не равна одобрению магазина платёжным провайдером.
